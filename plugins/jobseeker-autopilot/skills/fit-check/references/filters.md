# Country visa notes (check current rules with a quick web search when it matters)

- Germany: EU Blue Card when the salary meets the yearly threshold (lower threshold for shortage/IT roles); any employer can hire.
- Netherlands: highly skilled migrant route; the employer must be an IND recognised sponsor. Recruiters: the end client must be.
- Lithuania / Estonia: work permit or EU Blue Card through the employer; IT roles are usually straightforward.
- Saudi / UAE / Qatar: employer visa; many postings prefer in-country or nationals.
- Singapore: Employment Pass (COMPASS points, salary minimum).
